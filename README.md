# Student-Record-Management-System

Student Record Management System using C

A C-based console application for managing student records efficiently using Singly Linked Lists and File Handling.

### Features
- Add, delete and update student records
- Search and display student details
- Sort records by name or percentage
- Save and load records using binary files
- Automatic roll number management


### Core Concepts
Structures • Pointers • Linked Lists • Dynamic Memory Allocation • File Handling • Modular Programming
